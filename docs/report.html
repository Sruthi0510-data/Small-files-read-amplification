A rewrite reads every byte and writes every byte, so the honest unit is the number of scans it takes to pay that back. The break-even target reaches 72.3% and repays itself in 1.8 scans; everything above it is a long tail bought at full rewrite price.

Pricing a performance claim

A claim of a 40% improvement, priced against this table: the cheapest rewrite that reaches it targets 1,024 KiB files, delivers 46.7%, and leaves 7,719 files behind, every one of them below the break-even size.

So the figure is reachable without fixing the layout. A performance claim without its starting layout is not a weak claim; it is not a claim.
